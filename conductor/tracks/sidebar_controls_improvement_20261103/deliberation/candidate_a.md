# Candidate A — Control density / progressive disclosure cluster

Collapse advanced controls behind "More" or accordion sections; reduce initial cognitive load; show only primary actions by default.

## Pros

- Directly addresses "panel density vs. scanability" gap (primary UX issue)
- Low risk — additive UI pattern
- Well-understood progressive disclosure pattern

## Cons

- May not address grouping or discoverability
- Requires state management for collapsed sections
